# Kezelvi — Cuando te veo canto

Página estática inspirada en la referencia visual: ventana tipo macOS, paisaje ilustrado, portada translúcida, panel de letra y reproductor.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: estilos responsive y efecto de vidrio esmerilado.
- `app.js`: controles del reproductor, sincronización de letra, menú móvil y copiar letra.
- `cover.svg`, `landscape.svg`: ilustraciones vectoriales originales.

## Activar la canción
1. Crea una carpeta llamada `audio`.
2. Sube tu archivo con la ruta `audio/cuando-te-veo-canto.mp3`.
3. Publica el repositorio con GitHub Pages.

La letra y sus tiempos son de demostración; reemplázalos por la letra real en `index.html` y modifica las marcas de tiempo de cada elemento `.lyric-line`.
